Política de Privacidade

1. Recolha de Dados

Recolhemos os seguintes dados pessoais:

  • Nome completo
  • Email
  • Morada para entrega
  • Número de telefone
  • Histórico de compras

2. Utilização dos Dados

Os seus dados são utilizados para:

  • Processamento de encomendas
  • Comunicação sobre o estado das encomendas
  • Envio de newsletters (opcional)
  • Melhorar os nossos serviços

3. Proteção de Dados

  • Todos os dados são armazenados de forma segura
  • Não partilhamos dados com terceiros
  • Utilizamos encriptação para proteger dados sensíveis

4. Direitos do Utilizador

O utilizador tem direito a:

  • Aceder aos seus dados pessoais
  • Corrigir dados incorretos
  • Solicitar a eliminação dos seus dados
  • Opor-se ao processamento dos seus dados

5. Cookies

Utilizamos cookies para:

  • Manter a sessão do utilizador
  • Lembrar preferências
  • Melhorar a experiência de navegação
